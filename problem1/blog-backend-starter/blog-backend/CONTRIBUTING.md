code # 贡献指南

## 提交

- 一个提交只做一件事
- 提交信息写成 `类型: 说明`，类型取 `feat` / `fix` / `docs` / `refactor` / `test` / `style` / `chore`

## 事故记录

线上出问题之后，在 `docs/incidents/` 下补一份记录，照 `_template.md` 写。

- 文件名：`YYYY-MM-DD-<一句话标题>.md`
- 正文不超过 10 行
- 必须写清：引入问题的提交（7 位短哈希）、作者邮箱、位置（`文件:行号`）、根因、处理
- 引用代码用相对链接，路径相对于当前文档所在目录
